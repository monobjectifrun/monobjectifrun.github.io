Politique de confidentialité

Dernière mise à jour : 24 mai 2026

1. Qui sommes-nous ?

Objectif Run est une application mobile gratuite de préparation au semi-marathon. Cette page décrit comment nous traitons vos données.

2. Données collectées

  • Données Strava (avec votre consentement) : activités running, distance, durée, allure, fréquence cardiaque, dénivelé, dates.
  • Données d'entraînement : objectif course, date de course, plan généré, séances complétées ou passées.
  • Données techniques : tokens OAuth stockés de manière sécurisée sur votre appareil.

3. Stockage

Les données sont stockées localement sur votre téléphone (base SQLite). Nous ne vendons pas vos données. Pas de revente à des tiers.

4. Strava

La connexion Strava utilise OAuth 2.0. Vous pouvez révoquer l'accès à tout moment depuis vos paramètres Strava ou depuis l'application (Profil → Réinitialiser).

5. Publicités

L'application peut afficher des publicités discrètes (ex. bannières) pour financer le service gratuit. Aucune pub pendant une séance d'entraînement.

6. Vos droits

Vous pouvez demander la suppression de vos données locales via la fonction « Réinitialiser » dans l'app ou par e-mail à netfdorian@gmail.com.
